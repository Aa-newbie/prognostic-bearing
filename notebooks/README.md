# บทเรียน — Bearing RUL Prediction

ชุด notebook 8 บทที่พาไล่ตั้งแต่ "สัญญาณสั่นคืออะไร" จนถึง "ทำนายว่าลูกปืนเหลืออีกกี่ชั่วโมง"

## สามบทที่ไม่ควรข้าม

ถ้ามีเวลาจำกัด อ่านสามบทนี้ก่อน — เป็นบทเรียนที่ใช้ได้กับงาน ML ทุกงาน ไม่เฉพาะเรื่องลูกปืน

**บทที่ 4** — data leakage เกิดขึ้นได้อย่างไรโดยที่โค้ดไม่ error

**บทที่ 7** — ทำไม RMSE ที่ดูน้อยถึงยังบอกอะไรไม่ได้ ถ้าไม่มี baseline เทียบ

**บทที่ 8** — การทดลองที่แสดงว่าการแบ่งข้อมูลผิดวิธีทำให้ R² กระโดดจาก
**−155 เป็น 0.9995** ได้ ด้วยโมเดลและข้อมูลชุดเดียวกันเป๊ะ
